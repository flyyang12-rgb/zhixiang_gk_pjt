## 1. 定位

帮助没有可靠全省位次的学生与家长，了解专业学什么、怎样学习、有哪些职业路径，并保存一份可以继续讨论和核验的专业探索清单。

学生自主决定关注哪些方向。系统提供资料、比较与解释，不从岗位样本、校名或几次聊天推断个人适合度。

### 使用者与已确定范围

- 学生：了解专业的实际学习内容，表达想了解和暂不考虑的方向。
- 家长、兄姐与亲友：理解学习和职业门槛，保存担心、条件和待核验问题。
- 数据维护者：审核专业材料，补充来源，公开说明缺口。
- 首期档案省份仍为河南、山东、河北，不扩充省份承诺；全国学校只作浏览及学习资料入口。
- 没有确认具体年级、学生选科组合或专业兴趣，不为用户预设画像，不新增强制采集字段。

## 2. 要解决的问题

| 家庭问题 | 应得到的帮助 | 完成标志 |
| --- | --- | --- |
| 名称相近的专业有什么差别 | 看课程、学习活动与职业方向的并排证据 | 能说出至少一项有来源的区别，或明确目前证据不足 |
| 我是否愿意继续了解这个专业 | 看经核验的学习内容并自己记下意愿 | 可收藏、暂时排除或保持未决定，不被强迫选定 |
| 本科毕业后有哪些路径 | 已审核方向及读研、考证等门槛 | 方向与门槛有来源；没有材料的部分保持未知 |
| 父母和学生讨论后总是忘记 | 专业备注与简短探索简报 | 刷新能找回备注，可复制专业讨论材料 |
| 没有位次，下一步做什么 | 针对当前专业的一个可执行核验动作 | 无须填假成绩或购买 AI 服务即可继续探索 |

首期成功标准是资料能帮助家庭讨论并保留进展，不以聊天次数、候选数量或“推荐命中率”证明效果。

## 3. 主流程与页面职责

主流程保留“基础信息 → 专业与学校”两步。以下是第二步内的操作，不新增步骤或独立大页面。

1. 建立或选择公开学生档案；无位次家庭默认引导到目标探索。
2. 浏览专业探索清单，或按名称/专业类别查阅专业目录；资料待补充的标准专业身份也可收藏和比较。
3. 打开专业详情：学什么、怎么学、职业路径、选科证据、资料缺口。
4. 收藏关注方向，选择 2—3 个专业比较，按需排除或恢复。
5. 记录家庭讨论备注，选择 1—3 个收藏专业生成并复制探索简报。
6. 需要解释时，从专业详情预填问题给顾问；需要查学习实例时打开学校详情。
7. 后续形成可靠规划位次后，在同一档案自动开启招生比较。

### 页面内容顺序

| 区域 | 内容与操作 |
| --- | --- |
| 基础信息 | 称呼、省份、科类、选科及公开共享提示；成绩和位次对探索可空 |
| 工作台首屏 | 当前为目标探索的简短说明、专业清单、搜索/类别、收藏入口 |
| 专业详情 | 学习内容 → 学习活动 → 职业路径/门槛 → 已知/未知选科证据 → 学校例子 → 一个核验动作与收藏/备注/问顾问 |
| 收藏弹层 | 关注专业、备注、专业比较与探索简报；保留学校收藏入口 |
| 模考入口 | 次要操作；无位次时不能占据专业清单之前的大块首屏 |
| 学校详情 | 沿用唯一抽屉，展示学校例子来源范围和招生资格缺口 |

## 4. 功能要求

### E01 基础信息与模式

- 探索建档只要求现有基础字段；不要求分数、位次、问卷、家庭预算或自定义权重。
- 默认选择目标探索；已有可靠位次的家庭仍可明确选择填报入口。
- 未知成绩与位次为 null，不存 0、不创建空模考坐标。
- 有效工作台模式继续以规划位次为准；不改写建档时 planning_mode。
- 公开共享提示出现在建档与保存位置，使用昵称即可，不要求身份信息。

### E02 专业清单与目录

- 无规划位次时，不计算或展示专业综合分、适合度、推荐置信排名、三档推荐或冲稳保。
- 首屏最多 9 个专业，优先使用完整条目：至少一项已核验课程/培养事实、一项已核验学习活动及一个已审核职业方向。其次展示部分审核资料，再展示数据库中资料待补充的标准专业身份作为入门方向（2026-09-27用户要求）。身份条目只展示名称、类别、代码和缺口，不计入已审核数量，不发布待审核原文；已排除、硬条件不符和资料失效的条目不进入首屏。选科要求、职业门槛或学校例子缺失分别披露，不以“不限”或通用结论填充。
- 首屏条目按标准专业类别、专业代码、ID 的确定顺序展示，不通过未来信号、招聘规模、校名或用户备注产生“最适合”排序。卡片说明顺序用于浏览。
- 可浏览全部具备审核证据的目录，支持名称搜索、类别筛选及分页。搜索与选择不改变规则权重，也不写入历史偏好表。
- 搜索专业确实存在但尚无审核资料时，说明“资料待补充”，不能解释成专业不存在、不值得学或没有就业。
- 明确选科要求须来自适用范围清楚的官方材料。不满足已核验要求的条目不进入当前探索清单；可在目录查看原因。要求未知时标记待核验，不能默认“不限”。
- 某学校某年的要求只适用于该招生对象，不能提升为该专业全国统一要求。单校条件不满足只标记该学校例子或招生对象，不因此删除整个专业方向；专业清单的硬过滤必须有适用于当前档案范围的证据。
- 完整条目与有缺口条目数量、资料时间来自接口；不硬编码“全部专业”或已审核总数。

### E03 专业详情与事实来源

每个专业详情按以下结构展示，未知部分保留明确空状态。

| 内容 | 必须包含 | 缺失处理 |
| --- | --- | --- |
| 专业身份 | 标准 ID、代码、名称、类别 | 无可靠映射时不作为正式条目导入 |
| 学什么 | 核验过的代表性课程与培养内容 | 显示“课程材料待补充”，不由 AI 拼课程 |
| 怎么学 | 有官方材料支持的学习活动，例如实验、项目或实践安排 | 不靠专业名称猜测学习负担或性格要求 |
| 职业路径 | 最多 3 个已审核方向，标注读研、考证等门槛及依据 | 少于 3 个按实际显示；零个明确说资料不足 |
| 选科证据 | 具体要求、学校/省份/年份等适用范围 | 未知不当不限，不把历史要求当当年资格 |
| 学校例子 | 最多 2 所有具体专业材料的学校，证据类型和来源范围 | 无例子仍可探索专业，不从校名、学校线或未核验组名猜专业 |
| 待核验问题 | 当前缺少什么、一个家庭可执行动作 | 不把缺口转换成专业前景差 |

- 用普通家庭能理解的短句解释；课程名称仍保留官方写法。
- 课程及学习方式材料来自院校官方培养方案、专业介绍或同级权威材料。每条保存发布方、标题、URL、材料年份、核验时间及适用学校/专业范围。
- 每条展示事实关联具体材料与定位信息：PDF 页码、页面章节或标题锚点；至少能让维护者和家庭定位对应内容。原锚点或独立定位字段须保留，URL 规范化不丢失定位。审核记录包含核验人、时间、结论与理由。不能只挂一个官网首页，不能把 HTTP 可访问、source_urls 非空或 AI 生成时间当作人工核验通过。
- 学校培养方案是该校实例，不能宣称全国专业课程完全相同；摘要不得改变原材料意思。指定学校/年份材料缺失时显示该范围缺口；其他范围材料只能明确标注为另外的实例，不能静默回退后沿用当前范围标签。
- 分开表达学习前置知识、大学课程先修条件、招生选科资格和职业准入门槛。某课程需要数学基础只作为学习事实；不能自动转换成全国统一选科要求。只有当前范围适用的已核验招生条件参与资格硬过滤；考证或读研门槛亦不等于高考报考资格。
- 专业—职业映射由维护者审核。资料之间存在冲突时显示具体冲突和范围，不挑选有利材料凑结论。
- 招聘统计和官方未来证据作为可展开补充。招聘失效按既有规则降级；未来证据过期变未知，二者均不阻断课程、职业路径和收藏。
- AI 和用户备注不能成为事实来源。

### E04 专业比较

- 在工作台或收藏中选择 2—3 个专业，沿用弹层或现有工作台区域。
- 比较学习内容、学习活动、职业方向与门槛、选科证据和资料缺口。
- 来源支持逐项查看。不同学校实例需分别注明学校与年份。
- 只并排显示证据，不给赢家、总分、个人适合度或保证就业结论。
- 缺字段的专业仍可比较，缺口可见；不能把空值转为 0 或用 AI 补齐。
- 未选足 2 个或超过 3 个时有明确操作反馈；关弹层恢复焦点与原清单状态。

### E05 收藏、排除与家庭备注

- 使用现有 profile_saved_items；关注/排除与备注按学生档案持久化，不新增家庭偏好或问卷表。
- 收藏成功显示专业和档案称呼；刷新后从收藏进入同一专业详情，不受首屏或当前分页限制。
- 已收藏专业不因分页、证据过期或进入招生比较而丢失；专业资料不可用时仍显示已有收藏和备注，提示重新核验。
- 专业名称修订保持同一标准 ID；资料撤回与取消收藏分开处理。撤回事实不再出现在有效详情、比较、简报或顾问依据中，收藏和备注仍能找回并显示具体缺口。
- 排除后不出现在当前探索清单，目录仍可查看及恢复；排除与取消收藏区分。
- 备注最多 500 字，允许写意愿、担心和待核验问题；切换状态不覆盖备注，不改变自动规则。
- 用户没有收藏或暂时无法决定时，正常显示空状态，不自动收藏。

### E06 专业探索简报

- 选择 1—3 个已收藏专业，生成手机可读的简报并复制纯文本。
- 每个专业包含：用户关注状态、最多两个有来源的学习/职业依据、一个主要未知项、原始家庭备注和一个核验动作。
- 显示生成时间、实际来源年份及当前有效模式说明；无规划位次时说明“暂未形成可靠位次，当前只做专业探索”。获得位次后仍可生成专业简报，说明“当前材料用于专业探索，招生判断另看当前位次与资格”，不再声称没有位次。不能把生成时间当数据年份。
- 材料不足时如实说明，仍可保留专业与备注；不得填“前景好”“适合你”或报考风险。
- 保留 1—4 校学校简报，两种对象的字段与说明分别处理。
- 不新增 PDF、分享链接或正式志愿表；材料中的档案与备注仍来自公开共享数据库。
- 复制失败提示可手动选取文本，不能显示虚假的“已复制”。

### E07 顾问

- 从任一有审核证据的专业详情或已收藏专业进入，焦点由专业 ID 确认，服务端重新读证据，不局限于工作台首屏 9 个专业。已收藏且资料撤回的有效 ID 可以解释资料缺口及原始备注；不得引用撤回事实。未审核且未收藏者说明资料待补充，不创建事实焦点会话；不存在的 ID 返回不存在结果。
- 入口只预填具体学习或职业问题，不预填“为什么放在这个推荐档位”。首次发送才创建会话。
- 回答课程与门槛时，只使用当轮已核验材料，注明实例范围；兴趣和家庭条件只作用户自述。
- 无位次时不回答能否录取，不用分档或分数证明个人适合；面对用户要求“直接选一个”可说明证据差异并追问意愿，不能创造适合度结论。SPEC 的明确表达要求受此边界约束；资料缺失不能成为劝退专业、强选赢家或评价前景差的依据。
- 保留事实/决策问题的“已知、未知、下一步”边界及自然短答；普通情绪、问候不强套结构。
- 未配置、超时或失效时，同一材料与问题可用本地解释；专业比较与简报直接由确定性逻辑生成，不依赖外部 AI。

### E08 后续进入招生比较

- 仅有分数或校内名次时继续探索。
- 首次形成有效全省规划位次后自动开启已有学校/招生单元与专业交叉候选，不要求重建档案。
- 保留收藏、排除、备注及会话；未知招生证据仍未知，不能因为进入填报就补齐。
- 有位次流程的权重、数据粒度、省份制度隔离和原有待完善项按 SPEC 继续验收。

## 5. 内容与数据最低要求

- 复用 majors、data_sources、已审核职业方向、收藏和会话，新增学习证据的持久化结构由任务 01 明确。
- 事实标注 reviewed/待核验状态、来源范围和日期；细化枚举时与既有 verified/pending 审计语义保持一致。
- 公开材料只读保存来源登记。人工审核、幂等导入及针对本次批次撤回必须有明确操作；不能手工改几条生产记录掩盖导入问题。
- 首批专业以现有池和可获得官方材料选定，不能默认九个全部齐备。覆盖报告分别统计学习材料、职业方向、选科依据和学校例子。
- 首批正式内容至少有两个资料完整的专业可真实比较；不足时功能可以开发验证，但产品不能通过首期内容验收。
- 测试替身只进入独立测试环境，不得作为正式证据导入。
- 测试和内容审核不读取或导出真实学生档案、成绩、聊天。
- 登记正式内容批次、源材料校验值与证据 ID；详情、比较、简报和顾问共用当前有效材料及标识。每次重新生成详情/比较/简报，以及顾问每次发送前读当前有效材料；已打开的旧内容在重新生成/发送时刷新或提示变更，不要求后台实时推送。不用旧聊天中的事实覆盖新材料。首期只验证当前材料一致性，不增加历史版本浏览或可复现快照承诺。

| 家庭简报 | 当前以学校为对象 | 新增 1—3 专业探索简报 |
| 顾问专业焦点 | 从当前 dashboard.cards 查找 | 全部有审核证据的专业可聚焦，学习证据进上下文 |
| 学校实例 | 专业名查询历史招生，可能混淆资格与浏览 | 来源范围明确，仅由具体专业证据建立例子 |

## 7. 本期范围外与后续要求

本期不增加测评、强制兴趣/家庭预算采集、自定义权重、个性化适合度、实时联网顾问、收入预测、自动志愿表、更多省份完整录取推荐或新账号体系。

全国地图和已有招生流程保留，优先级让位于探索闭环。完整档案编辑、复制、招生 PDF 快照链路、历史版本等既有待完善要求继续记录，不作为探索产品功能的前置条件。每日额度、密钥、数据库隔离和实际部署验证属于既有发布要求，发布前必须有独立记录，不能以本期未改相关功能宣称它们已通过。
