# 知向使用指南

适合学生与家长共同阅读。安装见 [README](../README.md)，技术故障见 [维护指南](MAINTENANCE.md)。

本页说明当前工作区实现；正式服务器尚未更新。无位次探索清单、目录、学习详情、收藏、专业比较/简报及顾问学习材料已接入并通过独立环境测试。真实资料仍待真人审核，家庭走查与正式环境尚未验收，见 [任务计划](EXPLORATION_TASKS.md)；不能把测试中的合成资料当成正式覆盖。

档案、收藏、备注和顾问聊天保存在公开共享数据库，所有访客都能查看、修改和删除。关闭浏览器、清理浏览器记录不会删除服务器上的档案。

## 1. 建立或继续档案

1. 打开网站，填写学生称呼、省份、科类和选科。称呼可以用便于区分的昵称。
2. 默认选择“目标探索”，不要求分数或位次。已有成绩时可选“志愿填报”，填写分数；位次不确定就留空，不要填 0，也不要用班级、学校排名代替。
3. 点“保存并开始探索”（志愿填报为“保存并开始分析”），进入“专业与学校”工作台。没有可靠位次时直接查看专业探索清单，不显示综合分、三档或冲稳保。
4. 继续以前的记录：打开“历史档案”，选择对应学生。它是公开列表，不是个人私密空间。

目前可以新建、切换和删除档案，并持续记录模考；尚无复制、重命名或完整基础资料编辑入口。省份、科类或称呼填错时可重新建档，确认新档案无误后再自行决定是否删除旧档案。

## 2. 记录每次模考

无位次时先展开工作台下方的模考记录，再点“记一次模考”；已有位次时记录区直接显示。填写考试名称、日期、分数、可靠全省位次和可选备注，再点“保存为当前坐标”。

| 页面内容 | 怎么理解 |
| --- | --- |
| 当前坐标 | 最近保存的考试记录，用于展示当前成绩 |
| 规划位次 | 最近最多 5 次有效全省位次的中位数，用来对照学校历史招生位置 |
| 波动区间与稳定度 | 提醒参考坐标的稳定程度，不是录取概率 |
| 只有分数，没有位次 | 这次成绩不参与规划位次；以前有效的位次仍可继续使用 |

例如三次位次为 10,000、12,000、30,000，中位数是 12,000。系统不平均裸分，也不预测高考成绩。首次形成规划位次后，原先的目标探索档案会自动显示学校候选。

录错的模考可在轨迹中删除；删除当前坐标时系统恢复最近一条记录。操作后核对当前成绩和规划位次是否符合预期。

## 3. 比较专业与学校

没有规划位次时，探索首屏最多显示 9 个专业，顺序不表示适合度。可按专业名称、类别查阅分页目录；标准专业存在但资料尚未审核时，名称搜索仍可打开“资料待补充”的详情。清除筛选可回到首屏。

打开专业详情，分开查看课程、学习活动、学习准备、招生选科条件和职业方向。逐条展开来源可核对学校、材料年份、发布方和原文位置。学校实例只说明该校的培养材料，不表示当前省份当年可报或位次可达；未知选科要求不等于不限。返回或按 Esc 后保留目录页码与筛选。

有规划位次时，专业分为“优先了解 / 值得比较 / 谨慎报考”，每档最多 3 个。它们是比较顺序，不是性格结论，也不是“最适合你”的承诺。打开专业卡，查看就业方向、培养门槛、进入该档位的原因和待核验问题。

| 看到的提示 | 当前能做什么 |
| --- | --- |
| 暂不评分 | 有效证据不足，先看已知的就业方向和风险，不把它理解为 0 分 |
| 当前没有可比招生记录 | 可以了解学校；不能据此判断能否录取 |
| 只有专业组线 | 专业组是一组一起招生的专业；查到组的投档线不等于确认组内有目标专业 |
| 官网待核验 / 暂无经核验优势专业 | 当前缺少合格证据，不代表学校没有官网或优势专业 |
| 就业数据降级 | 最近公开岗位样本不足或过期，不再用于就业排名，也不代表该专业没有工作机会 |

学校候选按冲、稳、保每档最多 2 所展示。先核对省份、科类、年份、选科要求及具体专业，再看历史最低位次。河南改革前文理科不能与 2025 物理/历史专业组直接混算。

从地图、工作台或收藏点学校名称，都在右侧打开同一个详情抽屉。查看学校属性、经核验的优势专业、招生单元及来源；点明确标注的官网链接才会打开外部网站。无档案也可浏览学校基础信息。

按 Esc、点关闭按钮或遮罩可关闭学校详情；移动端显示全屏抽屉。地图省份筛选只影响当前浏览范围，不会变成家庭偏好或改变推荐规则。

## 4. 收藏、备注和家庭比较

1. 在探索专业旁点“关注专业”，或在学校旁点“收藏学校”，核对成功提示保存到了哪个公开学生档案。
2. 打开“我的收藏”，点专业或学校名称可回到详情，包括首屏之外的专业；点“移除”取消收藏。
3. 给收藏项添加家庭备注，例如“核对住宿费用”“想了解转专业要求”，最多 500 字。备注会公开保存，但不会影响评分或冲稳保。
4. 专业与学校分开勾选。选择 2—3 个关注专业，点“比较…个专业”，查看课程、活动、职业门槛、选科依据及缺口；顺序按选择，不给赢家、总分或个人适合度。逐条展开来源核对学校、年份和原文位置。
5. 选择 1—3 个关注专业，点“生成专业简报”，每专业保留最多两个实际依据、一个主要未知项、原始备注和一个核验动作。可复制纯文本，失败时手动选取下方文本。重新生成会读取当前材料、备注和有效模式，撤回资料不再充当依据；获得位次后仍可生成学习简报，招生判断另看位次与资格。
6. 勾选 2—4 所目标学校，点“比较已选…所”，集中看城市、层次、招生位置、选科和缺口。下方会自动生成简短对比解释；外部 AI 不可用时用本地解释。
7. 勾选 1—4 所学校，点“给爸妈看”，打开学校家庭简报并复制纯文本。专业简报与学校简报不生成公网分享链接；其中的收藏和备注本身仍来自公开档案。

排除专业与取消关注含义不同。探索详情中的“暂时排除专业”记录排除状态，需要时再点“恢复并关注”；切换状态保留原始备注。专业改名或材料撤回仍按原 ID 打开收藏，失效材料显示具体缺口。“刷新当前材料”会重新读取现有材料和已保存备注。目前不支持手动拖动候选顺序。

比较与简报都留在现有收藏容器，点“返回收藏”或按 Esc 返回选择并恢复按钮焦点，再按 Esc 关闭收藏。材料读取失败会显示中文重试入口，不继续展示上次生成的事实。

## 5. 向规划顾问追问

从学校或专业详情点“问顾问”，系统会预填具体问题。先检查或修改，再点发送；仅打开页面不会发送，也不会保存空会话。

专业问题可以围绕首屏以外的已审核方向继续问课程、学习活动、职业门槛和资料缺口。课程先修只说明大学学习准备，不等于高考报考资格。未关注且没有有效学习/职业资料的专业，首次发送会提示“资料待补充”；已经关注或已有会话的方向即使资料撤回，仍可讨论具体缺口和原始备注，每次发送都会重新核对当前材料，不把旧回答当作事实。

可直接问“这个学校的计算机专业有本省招生证据吗”。普通会话中提到学校时尽量写完整名称，避免“理工”“师大”等多义简称。成功识别后，后续可用“它”“这个学校”继续追问。

顾问说明“现在能确定、现在还不能确定、下一步只做”的边界。它查询的是当前数据库，不会实时上网替你补齐招生事实。问候、感谢等普通聊天不必套三句话。

历史会话可以继续，发送失败时使用“重新发送”。删除会话需要确认；删除后无法从界面恢复。学校比较中的自动解释不写入聊天历史。

## 6. 导出与保存讨论材料

顾问页面顶部有“导出 PDF 报告”。PDF 即时生成并下载，不另存到服务器；内容取自已保存基础档案和推荐快照。

**当前 PDF 不自动重新生成候选，也不包含完整收藏备注。** 新档案或尚未生成快照时，可能只得到基础信息及“尚未生成候选清单”的提示。报告生成时间也不等于招生数据年份。家庭需要分享当前收藏与备注时，优先使用“给爸妈看”。

PDF 导出失败时请维护者检查服务端 Chromium 与数据库，见维护指南。下载后核对学生、规划位次、数据年份、来源和风险，再用于家庭讨论。

## 7. 删除档案与常见疑问

在“历史档案”找到目标学生，点删除，仔细核对确认框里的学生称呼与成绩。确认后会永久删除关联收藏、模考、推荐及顾问聊天，其他访客也无法再看到。没有回收站。

- **刷新后找不到刚才的内容：**先查看历史档案是否选中了另一位学生，再确认保存是否成功；浏览器记忆的当前档案 ID 不等于数据本身。
- **为什么学校少或没有：**先查规划位次，再看当前省份/科类的数据覆盖和具体专业证据。系统不会为凑数补造学校。
- **为什么与考试院当年计划不同：**当前重点是 2023—2025 历史证据；正式填报必须重新核对当年招生计划、专业组成员和章程。
- **为什么 AI 不能直接拍板：**顾问只能解释当前证据；冲稳保、专业档位和排序由确定性规则生成。
