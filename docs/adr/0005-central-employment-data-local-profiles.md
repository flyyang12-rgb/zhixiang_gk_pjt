# 集中采集公共就业数据，学生档案保持本地

公共招聘数据由统一服务端每日采集、去重、归档并生成版本化统计，客户端启动时自动同步；学生成绩、位次、收藏和家庭信息第一版仍只保存在本机 MySQL。集中采集避免每个客户端重复访问招聘来源并便于统一修复来源适配器，本地档案则延续现阶段的隐私边界。原始岗位仅保留最近三十天，匿名每日统计长期保留；超过七天未成功更新的数据停止参与专业排名。
