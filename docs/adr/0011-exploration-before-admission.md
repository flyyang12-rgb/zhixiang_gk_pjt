# 无可靠位次时优先探索专业

2026-09-26，用户确认首要场景为“没有可靠位次时探索专业”，要求先确定产品形态、输出需求与任务拆分。

首期帮助学生与家长了解专业课程、学习方式和职业路径，保存关注项、备注与专业探索简报。没有规划位次时不启用专业综合评分或三档，专业目录的顺序只服务浏览。规则评分继续用于已有规划位次的招生比较，既有权重不在本次改变。

理由是无位次阶段尚不能评估院校可达性，招聘样本和政策信号也不能证明某名学生适合某专业。先让资料支持真实讨论，再由家庭自主关注和核验；就业数据过期或 AI 不可用不应阻断该过程。

新增课程/学习材料必须有官方来源与适用范围。没有资料时公开说明缺口，不能用模型常识补齐。学习用学校例子不等于本省当年可报证据。

实施保持两步主流程、公开共享模型及 Supabase/Express 架构。增加可靠位次后保留探索记录并自动开启招生比较。具体要求与验收见 `docs/EXPLORATION_PRD.md`；当前业务实现与服务器旧版均须另行验收。

本决策限定 ADR 0008 的综合评分在有规划位次时使用，不取消其官方证据、有效期与权重约束。
