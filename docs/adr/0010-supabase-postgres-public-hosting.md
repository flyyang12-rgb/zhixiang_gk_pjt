# 公网版本统一使用 Supabase PostgreSQL

2026-08-16，用户决定将知向公开给亲朋好友使用，并明确取消注册和档案隔离。所有访客可以查看、修改和永久删除所有公开档案与顾问聊天。该访问模型是有意的公共共享模型，不宣称具备个人数据隔离能力。

应用统一从本机 MySQL 迁移到新加坡区域的 Supabase PostgreSQL，不再维护 MySQL 兼容路径。浏览器不直接操作 Supabase；Vue 前端仍通过服务端 API 读写，由后续 Vercel 服务端运行环境保存数据库连接和 AI 密钥。Supabase 暂时只承载数据库，PDF 生成后直接下载，不持久化。

迁移只复制院校、专业、招生、就业及来源核验等公共基础数据。本机既有学生档案、收藏、推荐结果和顾问聊天不上传。新上线后产生的档案和聊天将作为全站公开共享数据保存。

AI 顾问与 PDF 生成分别设置全站每天 200 次成功额度，按北京时间零点重置。失败请求不扣额度，平时不显示剩余数量；达到额度后禁用对应操作并提示次日再试。额度实现属于后续公网部署迭代。

本决策取代 ADR 0001、0005 与 0009 中关于本机 MySQL、学生档案仅本地保存和私有 Docker 部署作为目标运行形态的部分；规则引擎、事实来源和 AI 权限边界保持不变。
