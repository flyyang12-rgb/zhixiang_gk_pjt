# ADR 0006：分离招生单元粒度与专业交叉匹配

## 状态

已接受。

## 决策

招生记录显式标记为具体专业、院校专业组或学校线。学校/专业组位次候选可以独立展示；只有具体专业记录或经官方目录核验的专业组成员才能建立专业—院校交叉匹配。

河南 2025 使用院校专业组投档，单年结果按保守固定区间生成并标记低置信度；改革前文理科不与物理/历史类合并。缺少组内目录时专业卡保持可见，院校评分因子为未知并按现有证据归一化。

## 原因

专业组投档线能够证明学校和组的历史投档位置，但不能证明组内一定包含某个具体专业。分层后既能提供可核验的学校参考，也不会通过名称匹配制造不存在的专业关系。
